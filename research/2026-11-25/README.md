# 有限趟比较下界、乘积表与精确选表

Miaozhen Yu（俞缪臻），2026-11-25。

所有十亿键结果使用互异键的均匀排列及输入读取前确定的表。普通无哨兵逐链线性插入计成功右移比较和停止比较。这里的表数量、解析比较下界和人工记录成本各有不同的计数对象。

## 晚间真实前缀、联合约束与占用矩

指定八趟表 $H_*=(62500000,16000001,4000003,1000003,250007,62501,15629,1)$ 的总平均键比较严格超过 41,641,698,503，第四趟均值严格介于 5,135,574,733 和 5,287,379,676。另对恰八趟、首间隔 62,500,000 的全部合法续表，严格超过 41,101,012,178；其中第二间隔不超过 2,850,000 时严格超过 50,002,479,509。[五轮证书、数据指纹与重放](prefix-certificates.md)

任意预定间隔表可用真实阈值状态表达，状态的复杂度受上一趟保留的依赖影响。六键合法前缀的碰箱反例、任意前缀的方差预算、记录事件的二矩界和六键真实均值核对见[占用与残差](occupancy-grid.md)。[Lean 模块](../../Shellsort/RecordMomentBounds.lean)验证了普通插入收费公式，以及已知真实矩时的记录概率和比较均值包围。十亿键数值来自有向的有限概率与有理证书。两项全表界仍按下面的设定成立。

## 七趟排除与八趟区域

先把首趟之后的数组作为真实状态。不同原链的键可用相互独立的顺序统计量比较，同源键保持其顺序；这给出第二趟同行和跨行逆序的下界。加上停止比较后，可逆的后缀插入记录还必须携带足够的熵来区分其入口状态。这三项在同一个成本预算内装配。对数区间、平方根和首链长度的有限分区使用有理数证书。[七章解析推导和证书](finite/README.md)

| $n=10^9$ 的范围 | 真实平均键比较下界 |
|---|---:|
| 所有至多七趟的合法固定表 | 50,054,104,988 |
| 所有至多八趟的合法固定表 | 40,912,368,737 |
| 恰八趟，首间隔 62,500,000，第二间隔在 7 至 2,604,166 之间 | 严格大于 50,490,000,000 |

## 逐表下界与松弛的边界

对每组整数 $2\le a<b\le183$，把小于 $10^9$ 的不同乘积 $a^i b^j$（非负指数）降序排列。16,471 组参数对应 16,462 张不同表，其中 10,069 组互素。固定且乘法独立的两个基数在 $n\to\infty$ 时给出 $\Theta(n\log^2 n)$ 的强制扫描量。[长度与扫描证明](products/01_乘积表长度与结构证明.md)

在全部参数组中，原温度网格加入前缀半群的位移支持后，有 1,765 组的整数下界提高。严格高于五百亿的仍有 6,694 组（6,402 组非互素、292 组互素）。对余下 9,777 组，各有一种满足所列支持、首趟真分布、总熵要求的人工记录律，其期望成本严格低于 499 亿。另有一个八趟松弛见证，每键人工成本介于 45.497636 与 45.497637 之间。这些构造说明哪些联合可达性约束还没有进入证明。八趟全域和低于五百亿的实际固定表仍待判定。[容量推导](products/02_批量比较下界证明.md) · [八趟见证的约束](products/eight_pass/semigroup_support_audit.md)

## 矩、停止比较与精确选表

- 对前缀矩 $m_{k,q}$，若初值至多为 1，$m_{k,1}^2\le m_{k,2}$，且 $m_{k+1,q}\le m_{k,q}/4+2^{130q}m_{k,q-1}$ 对所有 $q\ge2$ 成立，则 $m_{k,q}\le(4/3)^q2^{65q(q+1)+130}$，对前缀长度一致。Lean 已证明这个矩递推。将某个具体采样器和实际比较收费代入时，还需证明它满足相应的矩与收费条件。[Lean 声明](../../Shellsort/AdjacentMomentEnvelope.lean)
- 对从零开始编号的排列 $x$，$b(x)=\min_i(i+x_i)$ 控制末趟能出现的非首纪录最小值个数，给出至少 $n-1-b(x)$ 次后缀停止比较。这项费用可以和成功右移的下界相加。程序还使用剩余逆序数和出口状态频数的 Huffman 下界；仅在候选严格劣于已知最优值时剪枝，以保留全部并列解。[后缀证书](search/p09_certificates.py) · [精确搜索](search/p09_information_search.py)
- 三种搜索在 $2\le n\le9$ 的最优成本和全部并列表上一致。$n=5$ 有两张最优表 $(1)$ 与 $(4,1)$；$n=9$ 唯一最优表为 $(6,1)$，均值 $10729/504$。在这个范围，加入 Huffman 项没有多剪掉一个节点。
- 另一条统计选表路线给定非负的逐路径收费分解和联合矩界，按独立评分选择未来均值至多为 $5S_n$ 的表，$S_n$ 由分解系数预先指定。相应查询下界限定于只能独立抽样评分的黑箱候选。恢复实际程序的运行界还取决于评分能否中断及输入准备的开销。[统计选择器和参数检验](search/p09_statistical_selector.py)

## 复现

在本目录运行以下命令。前三项分别重算七八趟有理证书、16,471 组的逐表下界和人工见证、以及精确搜索；第四项检查统计选择器的有限算术。第二项从两个基数重新生成全表，在临时目录产生并核对大结果文件。Python 3 标准库即可运行这四项。

```sh
python finite/scripts/verify_all.py
python verify_products.py
python search/p09_information_search.py --min-n 2 --max-n 9 --output search-results.json
python search/p09_statistical_selector.py --verify --output selector-results.json
```
